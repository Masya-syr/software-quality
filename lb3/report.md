## Test Design

### calculateDiscount

Обрано такі умови:
1. Вірні данні ціни та вірна, не нульова знижка;
2. вірна ціна та 0% знижка;
3. вірна ціна та 100% знижка;
4. обробка помилки невірної ціни;
5. обробка помилки невірної знижки.

### validateQuantity

Граничні значення:
1. значення < 1
2. 1 <= значення <= 10
3. значення > 100
4. не ціле число

### getShippingCost

Дані можна розбити на три гілки:
1. значення < 0
2. 0 <= значення < 1000
3. значення > 100
